# 🎬 演示脚本（录屏用）

按顺序操作，每个场景一句话解说，全程约 3 分钟。

## 准备
```bash
# 终端 1
cd backend && python -m uvicorn app.main:app --port 8000
# 终端 2
cd frontend && npm run dev
```
浏览器打开 http://localhost:5173

## 场景 1：创建角色（30s）
1. 输入角色名「艾琳·影刃」
2. 种族选 **Elf**，职业选 **Rogue**
3. 技能选择点选 **Stealth + Perception**（展示 skill-choices 交互）
4. 属性生成选「骰点（4d6 取 3 高）」
5. 点「开始冒险」
- 📢 解说：*标准购点/骰点、种族加成、技能熟练选择，全部由真实 5e SRD 规则计算*

## 场景 2：DM 开场与自由探索（40s）
1. 创建后自动触发 DM 开场（醉龙酒馆场景 + NPC + 悬赏告示）
2. 输入「我走向悬赏告示板，细看那张哥布林悬赏」
3. 输入「我向酒保打听锈矿山道的情况」
- 📢 解说：*AI 地下城主动态生成剧情，多感官叙事，NPC 有性格*

## 场景 3：规则检定（30s）
1. 输入「我悄悄潜行到角落，偷听灰袍老人在说什么」
2. 观察 **🎯 技能检定气泡**（Stealth：D20 + 修正）
3. 叙事基于真实骰子结果展开（成功/失败都合理演绎）
- 📢 解说：*关键：所有判定由规则引擎掷骰，LLM 只负责把结果讲成故事——这就是两阶段协议*

## 场景 4：遭遇战（60s）
1. 输入「我接受悬赏，前往锈矿山道！」
2. 遭遇哥布林 → 侧边栏出现**敌人 HP 条**
3. 点快捷按钮 **⚔️ 攻击** → 命中/伤害/击杀 → **XP +50**
4. 点击「🎲 掷骰」展示任意骰子
- 📢 解说：*战斗状态由引擎维护：攻击命中 vs AC、伤害骰、击杀得经验、升级自动加 HP*

## 场景 5：存档读档（20s）
1. 刷新页面 → 「📜 继续冒险」列表出现当前角色
2. 点击加载 → 角色卡（HP/经验/敌人）与对话历史完整恢复
- 📢 解说：*存档持久化，随时继续你的冒险*
